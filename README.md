# AOC 新公司 IC 讨论材料（PPT）

本仓库存放 AOC NewCo 投资委员会讨论材料的成稿与生成脚本。

## 成稿

- `AOC_NewCo_IC_Deck_2026-11-02.pptx` — 79 页，16:9
- `AOC_NewCo_IC_Deck_2026-11-02.pdf` — 同一版本的 PDF，便于快速审阅

### 结构

| 段落 | 页数 |
|---|---|
| 封面 | 1 |
| 执行摘要（本轮请批 + 六道关口挂接表） | 1 |
| 目录（十个部分） | 1 |
| 章节分隔页 | 10 |
| M01–M36 主文，一单元一页 | 36 |
| 附录页组总览 + 附-A 待定事项台账 | 3 |
| 附-C 原图档案索引 + F01–F26 一图一页 | 27 |

### 版式与配色

直接继承 BaseCure 原版（`210621_NewCo_Investment_Committee_discussion_materials_vF2.pptx`）的
slideMaster 与 slideLayout：顶部蓝条、结论式蓝色标题（`0070C0`）、左下 logo、右下页码域、
封面影像带与 CONFIDENTIAL 脚注均由原母版渲染。表头深蓝 `305496`，强调色 `FBAE40`。

每页构成：结论式标题 → 「本页主张」条 → 图／主表 → 本页要点 → 页脚（关键限制 2 条 ＋ 来源 ＋ 本页待定条数）。
版面按图的长宽比在「图左＋要点右」「上图下表」「要点卡条＋整幅决策表」三种之间切换。

## 生成脚本

- `tools/extract.py` — 解析 PPT 架构 MD 与 IC Memo v2（docx→md）为结构化 `content.json`
- `tools/gen.py` — 以原版 pptx 为模板生成成稿

脚本依赖未入库的原始素材（架构 MD、IC Memo v2 docx、BaseCure 原版 pptx），仅作留痕与复算用。

## 已知取舍

1. 备忘录中 46 行 × 5 列一类的大表在页面上按首表 4–6 行呈现，其余表只列标题并指回备忘录全表。
2. 正文字体为微软雅黑 ＋ Arial（原母版中文为宋体／华文楷体），以保证投影可读性。
3. 图为 docx 内的 PNG 位图（降采样至 1600px）。若可提供 `build/fig/*.svg`，可替换为矢量图，导入后图内文字仍可编辑。
