Platform unit

Same entry + same target cell + same main compartment. Reuse turns on these three; a shared disease name is secondary.

Platform test = platform-transfer gate

Repeatable functional delivery on two independent targets at one entry, one target-cell class, one payload chemistry and route, with traceable quality and obtainable rights. Read: second payload DYSF gives independent functional evidence at the same entry. One payload = single product.

Reusable: platform assets

Methodology; transferable formulation; negative results; quality–function rules. Service catalogue and a one-off positive are replicable, not reuse.

Not reusable

Entry, target cell, main compartment. Change one and it is a new unit, evidenced again; an inner read-out cannot stand in.
